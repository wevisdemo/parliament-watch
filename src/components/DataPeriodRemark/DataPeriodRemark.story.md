# \<DataPeriodRemark \/\>

- ใช้แสดงข้อความที่บอกว่าข้อมูลนั้นถูกอัปเดตล่าสุดเมื่อใด หรือว่ามีการเริ่มเก็บข้อมูลตั้งแต่เมื่อใดถึงเมื่อใด

## Props

| Props       | Type                     | Meaning                                                                                                                                                                                                                                                                                                     |
| ----------- | ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `updatedAt` | `Date \| string \| null` | วันที่ข้อมูลถูกอัปเดตล่าสุด หน้าแรกใช้ `timestamps.lastNodeUpdatedAt` หน้าร่างกฎหมายใช้ `timestamps.lastBillScrapedAt` ของ politigraph ส่วนหน้ารายละเอียดอื่นใช้ `updated_at` (หรือ `created_at`) ของ node นั้น                                                                                             |
| `variant`   | `string`                 | - `updated` (ค่าเริ่มต้น): อัปเดตข้อมูล <br/> - `coverage`: ข้อมูลครอบคลุมปี 2562–ปีล่าสุด พร้อมลิงก์ดูเพิ่มเติม (หน้าแรก) <br/> - `changed`: มีการเปลี่ยนแปลงล่าสุด (หน้าองค์กร) <br/> - `profile`: อัปเดตประวัติล่าสุด (หน้านักการเมือง) <br/> - `scraped`: ดึงข้อมูลจากเว็บต้นทางล่าสุด (หน้าร่างกฎหมาย) |
